## Risk monitoring dashboard

[Open the Risk Monitoring Dashboard](https://youngbayi666-star.github.io/ai_products/risk_monitoring_dashboard/) · [Source and setup](risk_monitoring_dashboard/README.md)

The dashboard provides a multidimensional pivot view and an interactive trend view for exploring simulated payment risk metrics. It runs entirely in the browser and does not upload user input.
