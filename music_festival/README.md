# ECHO WAVE 音乐节互动海报原型

可运行的营销互动大屏演示：全场共振谱待机屏 → 选择音乐人格和视觉风格 → 输入昵称与一句话 → 生成海报并匿名加入共振谱 → 扫码到手机保存或分享。ECHO WAVE 是本原型使用的虚构品牌。

**GitHub Pages 公开版**：在未连接 Supabase 时，共振谱是明确标注的单浏览器演示；要让所有人的声波跨设备汇入同一画面，按 [SUPABASE_SETUP.md](SUPABASE_SETUP.md) 启用免费项目。纯前端代码即可直连 Supabase，无须部署本地 Python 服务。

## 启动

需要 Python 3。在本目录执行：

```bash
python -m pip install -r requirements.txt
python server.py
```

电脑打开 `http://localhost:8765/`。手机与电脑连接同一 Wi-Fi 时可扫描结果页二维码；若系统防火墙拦截 8765 端口，请允许本地服务通信。建议以浏览器全屏方式在横向大屏演示。也可用普通电脑或手机宽度查看响应式布局。

## 演示重点

1. 待机屏展示参与数与匿名声波，每 5 秒同步一次。也可以在另一台设备打开同一网址并停留在待机屏，观察他人创作实时汇入。
2. 依次点选四种音乐人格；预览中的底图、主色、图形和声波都会改变。视觉风格另提供三种色调。
3. 输入昵称和一句话，点击生成。声波汇入共振谱后进入结果页，海报显示回声编号。
4. 扫码在手机保存 PNG，或在大屏下载、复制链接。局域网 HTTP 地址不支持部分手机浏览器的系统分享面板时，手机页会复制链接。
5. 输入页 60 秒无操作回到待机；结果页 30 秒自动清屏。

## 原型边界

四张 AI 生成的预审底图位于 `assets/`，浏览器完成个性化合成；演示无需 API 密钥，也不会为每位观众实时调用生图模型。共振谱接口仅保存匿名视觉参数、编号和时间，最多保留最近 80 条，服务重启后清空。分享链接则包含昵称与一句话，演示时勿输入真实隐私。正式活动需增加服务端内容审核、限时分享 token、图像清理和权益核销。

## 文件

- `index.html`、`styles.css`、`app.js`：大屏交互、结果页和待机共振谱。
- `poster.js`、`waveform.js`、`mural.js`：海报、人格声波与共振谱绘制。
- `share.html`、`share.js`：手机端保存与分享。
- `server.py`：本地静态服务、二维码和匿名贡献接口；GitHub Pages 使用 `echo-client.js` 与浏览器端二维码库。
- `supabase/setup.sql`、`supabase-config.js`：可选的跨设备共振谱配置。
- `PRODUCT_PLAN.md`：一页产品方案。
- `AI_USAGE.md`：AI 工具、提示词和候选人参与说明。
